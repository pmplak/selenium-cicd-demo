# Automation Enterprise Template

## Overview

Automation Enterprise Template is a production-oriented automation framework being built from scratch by following enterprise software engineering practices.

This repository is not only an automation framework but also a learning repository that demonstrates how enterprise teams design, document, review, and maintain automation projects.

The project follows an incremental implementation strategy where every feature is validated through Pull Requests before becoming part of the framework.

---

# Objectives

The primary objectives of this repository are:

- Build an Enterprise Selenium Automation Framework
- Learn Git and GitHub using real-world workflows
- Configure CodeRabbit as an AI Code Reviewer
- Integrate Jenkins CI/CD
- Implement Enterprise Automation Architecture
- Document every architectural decision
- Build reusable components for future automation projects
