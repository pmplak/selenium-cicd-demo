# Engineering Standards

## Java

- Follow SOLID principles.
- Keep methods small and focused.
- Avoid duplicate code.
- Use meaningful class and method names.

## Selenium

- Prefer Page Object Model.
- Avoid Thread.sleep().
- Use explicit waits.
- Keep one business scenario per test.

## API Automation

- Validate both status code and response body.
- Log requests and responses.
- Reuse API client methods.

## Maven

- Define plugin versions explicitly.
- Avoid duplicate dependencies.
- Keep dependency scopes correct.

## Documentation

- Keep README.md updated.
- Record every architectural decision.
- Update CHANGELOG.md for every feature.
