# ADR-001 : Adopt CodeRabbit

## Status

Accepted

---

## Context

The project requires automated AI-assisted code reviews during Pull Requests.

---

## Decision

Use CodeRabbit as the AI code reviewer.

---

## Benefits

- Automated Reviews
- Pull Request Summary
- Incremental Reviews
- Repository Learning
- Enterprise Configuration

---

## Consequences

Every Pull Request will be automatically reviewed before merge.
